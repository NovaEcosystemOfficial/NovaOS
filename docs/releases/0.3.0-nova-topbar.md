# nova-shell 0.3.0 — Top Bar 3.0

## Summary

Sostituzione visibile della Top Bar: chrome glass (non KDE), strut workspace,
rimozione pannelli Plasma, hook Control Center.

## Changes

- Altezza 36px, vetro RGBA + `_KDE_NET_WM_BLUR_BEHIND_REGION`
- Wordmark **Nova** + logo; centro libero; tray a chip glass
- Notifiche / rete / audio / batteria / ora → `open_control_center`
- CPU/RAM/Disco assenti dalla barra
- `nova-hide-plasma-panels` + avvio Shell senza `X-KDE-autostart-after=panel`
- Companion identity layout: nessun `defaultPanel` Plasma

## Install

```bash
nova-updater check
nova-updater apply
```

Poi **logout/login**. La barra Plasma stock non deve più apparire; resta solo
la Top Bar Nova glass.
