# Changelog — Nova Center 0.2.3

**Canale:** `stable`  
**Pacchetto:** `nova-center-0.2.3-1.nova.noarch`  
**Distribuzione:** solo via Nova Update (nessuna installazione manuale su `/usr`)

## Novità

- Dashboard con **stato generale** del sistema (ok / attenzione / critico)
- Utilizzo **CPU in tempo reale** (campionamento `/proc/stat`)
- Utilizzo **RAM in tempo reale**
- Utilizzo **disco** (root)
- **Uptime** aggiornato in live polling (2s)
- **Batteria** quando presente
- Layout Dashboard più chiaro (meter + sezioni)
- Modulo backend `dashboard.py` dedicato
