# Changelog — Nova Welcome 0.2.3 (NovaOS v0.2.3)

**Canale:** `stable`  
**Pacchetto:** `nova-welcome-0.2.3-1.nova.noarch`  
**Distribuzione:** solo via Nova Update

## Novità

- Wizard di primo avvio **Nova Welcome** (Qt/PySide6)
- Pagine: benvenuto, hostname, tema, ecosystem, riepilogo, pronto
- Autostart XDG una sola volta (`~/.config/nova/welcome-completed`)
- Shared helpers `nova_shared` (hostname, temi, launch Nova Center)
- Al completamento apre automaticamente **Nova Center**

## Installazione (manuale, sul sistema installato)

1. `nova-updater check`
2. `nova-updater apply`  
   oppure GUI Nova Update → Controlla / Installa

Non copiare file in `/usr` dalla macchina di sviluppo.
