# nova-shell 0.2.11 — Vision 2.0 Top Bar

## Summary

Top Bar allineata a Vision 2.0: pannello fisso con strut EWMH (non overlay),
chrome minimo, niente auto-hide / edge-reveal.

## Changes

- `TopBarManager` pubblica `_NET_WM_STRUT` / `_NET_WM_STRUT_PARTIAL` e tip `DOCK`
- Area di lavoro ridimensionata; finestre e X di chiusura sotto la barra
- Rimosso reveal al bordo superiore e le modalità auto-hide / hide-maximized
- Layout: Logo · (centro vuoto) · Notifiche · Wi‑Fi · Audio · Batteria* · Ora
- Rimossi dalla barra: CPU, RAM, Disco, kernel, widget tecnici, dock strip
- Altezza 32px

## Install

Solo via Nova Update (stable):

```bash
nova-updater check
nova-updater apply
```

Poi logout/login o `nova-shell`.
