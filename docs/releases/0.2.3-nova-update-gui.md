# Changelog — Nova Update GUI 0.2.3

**Canale:** `stable`  
**Pacchetto:** `nova-update-gui-0.2.3-1.nova.noarch`  
**Distribuzione:** solo via Nova Update

## Novità

- Pulsanti **Controlla aggiornamenti** e **Installa aggiornamenti** spostati sotto l’header (sempre visibili; non più sotto le liste espandibili)
- **Installa aggiornamenti** abilitato solo quando ci sono pacchetti pending
- Messaggio di stato che invita esplicitamente a premere Installa dopo un check con risultati

## Note OTA

1. `nova-updater check` → deve elencare `nova-update-gui` 0.2.3
2. `nova-updater apply` (o GUI) per installare
