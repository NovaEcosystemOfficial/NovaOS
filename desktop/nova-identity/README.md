# Nova Identity (Sprint 20)

Canonical branding assets and identity tools for NovaOS.

| Path | Role |
|------|------|
| `/usr/share/nova/assets/` | logo, icons, colors, fonts, wallpaper, splash, palette |
| `/usr/bin/nova-about` | ASCII identity banner |
| `/usr/bin/nova-{info,version,health,diagnose}` | CLI tools |
| Konsole `NovaOS` profile | Terminal colors + default |

Distributed only via Nova Update (`nova-identity` RPM).
