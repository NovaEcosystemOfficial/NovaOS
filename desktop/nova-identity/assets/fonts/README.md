# NovaOS shared fonts

Identity ships CSS/JSON tokens that prefer **Noto Sans** / **Noto Sans Mono**
(already common on Fedora-based images). Future sprints may vendor webfonts
under this directory; apps must load tokens from:

`/usr/share/nova/assets/fonts/novaos-tokens.css`
`/usr/share/nova/assets/palette/novaos.json`
