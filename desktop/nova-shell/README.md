# Nova Shell

**Top Bar 3.0** — glass strut panel (Vision 2.0). Not Plasma chrome.

Layout: Logo + Nova · (center free) · Notifications · Network · Audio · Battery* · Clock  

Tray icons open the Control Center hook (flyout stub until Control Center ships).
On start, Plasma panels are removed so only the Nova bar is visible.

```bash
nova-shell                 # GUI
nova-shell --json          # snapshot
nova-shell --hide-plasma-panels
nova-hide-plasma-panels
```

Install only via Nova Update (`nova-shell` ≥ 0.3.0). Logout/login after apply.
