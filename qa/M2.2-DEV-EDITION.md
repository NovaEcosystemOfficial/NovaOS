## Manual guest checklist (post-boot)

1. Login `nova` / `novaos` → Plasma desktop.
2. Firefox on panel / desktop / menu; open `https://example.com`.
3. Download a small file; open a PDF; visit GitHub / Vercel / Firebase Console.
4. In Konsole: `git --version && node -v && npm -v && python3 -V && pip3 -V && gcc --version && flatpak --version && ls ~/NovaWorkspace`
5. Optional: install Cursor AppImage per `CURSOR-READINESS.md`.
